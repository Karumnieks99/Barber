# BLADES & CO

[![Live Demo](https://img.shields.io/badge/Live%20Demo-karumnieks99.github.io%2FBarber-C9A84C?style=for-the-badge&logo=github)](https://karumnieks99.github.io/Barber/)

A premium barbershop landing page for **BLADES & CO**, Rīga, Latvia — built as a portfolio/demo project.

---

## Tech Stack

- **React 19** — UI
- **Vite** — build tool
- **Tailwind CSS v3** — styling
- **Framer Motion** — animations

## Sections

Nav · Hero · Services · About · Masters · Gallery · Testimonials · Booking · Footer

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

Output goes to `dist/`. Deployed automatically to GitHub Pages on every push to `master` via GitHub Actions.
